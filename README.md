# 芭樂熟客學堂

繁體中文、手機優先的 LINE 群組與社群經營教學。純 HTML / CSS / JavaScript，無建置或套件安裝需求。

## 本機啟動

在此目錄執行 `npm start`（需要 Python 3），或 `python3 -m http.server 3000 --bind 0.0.0.0`。

`npm test` 檢查 JavaScript 語法。使用瀏覽器驗證導覽、步驟展開、範本切換、複製與清單保留。

## 公開發布

可把本目錄當靜態網站發布；GitHub Pages 請在儲存庫 Settings → Pages 選 Deploy from a branch → main / root，再儲存。需先將檔案提交並推送到 GitHub。此專案未自動推送或啟用 Pages，不代表已公開上線。

## 內容與授權

沒有使用虛構成功案例或銷售數字。使用者提供的照片僅用於文字觀察，並未內嵌；主視覺是自行繪製的 SVG 示意圖。LINE 操作與政策請依官方最新資訊確認，本站非官方網站。

字型採用 justfont 粉圓體 2.1（SIL Open Font License，見 assets/OFL.txt），本地提供，不依賴第三方字型服務。清單進度只存在瀏覽器 localStorage，不收集個資。

## 小步驟教學

三堂教學（建立社群、發圖文、日常管理）各十步，每次只顯示一步；進度只存在瀏覽器 localStorage。畫面以文字示意，並非官方介面截圖，按鈕名稱與位置以手機實際版本為準。

新增溫和的訊息改寫建議、計價單位提醒、六種可複製符號，以及表情符號／LINE 表情貼／貼圖的區別。未公開私人對話截圖與頭像。所有訊息範本需先替換括號與核對當日資訊。
